# Milk Molars Mod

## Description

Milk Molars adds 2 new scrap to the game, Milk Molars and Mega Milk Molars. Milk Molars are big molar shaped vitamins inspired from the game 'Grounded' that you can use to upgrade personal and shared stats and abilities. The alternative currency system in LateGameUpgrades config must be enabled for players to recieve points. You can also just use these as regular scrap items as well.
